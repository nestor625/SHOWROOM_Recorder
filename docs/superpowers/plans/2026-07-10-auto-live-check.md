# Per-Channel Auto Live Check Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add opt-in, persistent, per-channel live monitoring on Mac and Windows while fixing Windows selected-stop so it terminates only the chosen recording.

**Architecture:** Each enabled URL owns one native background job and one generated worker. Workers probe with `streamlink <url> best --stream-url` every 60 seconds, start the existing recording command only after a live probe, publish per-channel status, and resume probing after a broadcast ends. The GUIs persist enabled URLs separately from channel data and use exact PIDs for stopping.

**Tech Stack:** Plain-text AppleScript, Bash generated by AppleScript, PowerShell 5.1, WinForms, launchd, Windows Scheduled Tasks, Streamlink 8.x CLI, dependency-free Bash source-contract tests.

## Global Constraints

- Do not change `channels.txt`, `channels.json`, `save_path.txt`, or `settings.json` formats.
- Auto-check is off by default and enabled independently per channel URL.
- Monitoring survives GUI closure and user login restart until explicitly disabled.
- Multiple enabled channels may record simultaneously.
- Probe interval is 60 seconds using `--stream-url`; recording uses `best -o <output> --force --retry-streams 30`.
- Preserve Mac `%Y-%m-%d_%H%M` and Windows `yyyy-MM-dd_HH_mm` timestamps.
- Preserve Windows `win/showroom-recorder.ps1` as UTF-8 with BOM (`efbbbf`).
- Add no package manager, framework, service, or runtime dependency.
- Do not commit, stage, or push unless the user explicitly requests it.
- Preserve unrelated untracked `.DS_Store` and `a.scpt`.

function Stop-RecordingByPid([int]$pid) {

function Refresh-RecordingList {
    foreach ($key in @($global:manualRecordings.Keys)) {
        if (-not (Get-Process -Id ([int]$key) -ErrorAction SilentlyContinue)) {

        $recordingList.Items.Add($entry.display) | Out-Null
    }
}

- [ ] **Step 4: Generate the per-channel worker safely**

`enableAutoCheck` writes `jobs/auto-<id>.sh`. The generated Bash worker receives all user values as single-quoted literals produced by AppleScript `quoted form of`; it does not interpolate names into executable syntax. Its control flow is:

```bash
while :; do
  write_status waiting "" ""
  if "$streamlink" "$url" best --stream-url >/dev/null 2>>"$log"; then
    timestamp=$(date +%Y-%m-%d_%H%M)
    output="$save_path/$name-SHOWROOM-$timestamp.mp4"
    while [ -e "$output" ]; do sleep 5; timestamp=$(date +%Y-%m-%d_%H%M); output="$save_path/$name-SHOWROOM-$timestamp.mp4"; done
    "$streamlink" "$url" best -o "$output" --force --retry-streams 30 >>"$log" 2>&1 &
    stream_pid=$!
    write_status recording "$stream_pid" "$output"
    wait "$stream_pid" || true
    stream_pid=""
  fi
  sleep 60
done
```

The real generated script also defines `write_status` using a temporary file plus `mv`, Base64-encodes URL/name/output fields before writing the pipe-delimited record, reads the current save path before each recording, caps its log at 1 MiB, and traps TERM/INT/EXIT to kill only its current `$stream_pid`.
